About Me

Clean Code
Responsive UI

I'm a dedicated Full Stack Developer based in Cabuyao, Laguna, Philippines, passionate about designing and building end-to-end web applications — from polished, responsive interfaces down to solid backend architecture and database design.

My day-to-day toolkit revolves around ReactJS, Blazor, ASP.NET Core and ASP.NET Web API on the frontend/backend, paired with Entity Framework Core, SQL Server (SSMS) and MySQL Workbench for data persistence. I also work comfortably with SOAP APIs, Windows Services, and use Git/GitHub and Azure DevOps to keep projects organized, versioned, and deployment-ready — with Docker and IIS for hosting.

I hold a BS in Food Technology from LSPU, and transitioned into software development through continuous self-driven learning and hands-on training — including a certification in Developing ASP.NET Core MVC Web Applications and TESDA courses in Computer Systems Servicing. I bring that same discipline and attention to detail into every project I build.
